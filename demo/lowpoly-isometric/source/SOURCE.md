# Islandia

A low-poly isometric world generated entirely in canvas 2D code, featuring procedural island generation, bouncing architectural blocks, floating clouds, and a gentle ambient chimes soundtrack.

## Deliverables
- `source/index.html`: Canvas container and module runner.
- `source/film.js`: Orthographic isometric rendering engine and animation loop (0-10s).
- `source/audio.py`: Procedural NumPy audio generator for nature wind and harmonious marimba/chime arpeggios.
