# Heat Leaves source

Source for the Chalkboard demo film, 39 s, 1920×1080, 24 fps.

## Build

Set `LIB` to the FilmCode library folder (the one with `core/` and `.venv/`):

```bash
export LIB="$HOME/.filmcode/library"
sh build.sh
```

`build.sh` renders the picture, writes the score, mixes the audio and masters to about −14 LUFS. It writes:

- `heat-leaves.mp4` — final render, also copied beside `DEMO.md`
- `heat-leaves.srt` — subtitles
- `../poster.jpg` — poster frame
- `out/video.mp4`, `out/mix.wav` — intermediates

Those outputs are gitignored. `music/music.wav` is regenerated by `music/score.py`.

## Inputs

Included: the browser film (`index.html`, `main.js`, `film.js`, `chalk.js`, `letters.js`, `stage.js`, `post.js`), audio (`mix.py`, `music/score.py`), voice lines and rendered WAVs (`tts/`), and the subtitle font.

Not included: the marimba samples (Versilian Community Sample Library, fetched by the library's `tools/fetch.sh`), the Kokoro voice model, and rendered outputs.
