# Alborada source

Source for the Watercolor Brush demo film (https://veqhxcsoalfnbsbycnwb.supabase.co/storage/v1/object/public/filmcode-demos/watercolor.mp4), 45 s.

## Build

Set `LIB` to the FilmCode library folder (the one with `core/` and `.venv/`):

```bash
export LIB="$HOME/.filmcode/library"
sh build.sh
```

`build.sh` renders the film, generates the score, mixes the audio and writes:

- `alborada.mp4` — final render
- `poster.jpg` — poster frame
- `out/video.mp4`, `out/mix.wav` — intermediates

Those outputs are gitignored. `music/music.wav` is regenerated by `music/score.py`.

## Inputs

Included: the browser film (`index.html`, `main.js`, `scene.js`, `engine.js`), paper generation and texture (`paper.py`, `paper.jpg`), audio (`mix.py`, `music/score.py`), voice lines and rendered WAVs (`tts/`), fonts and the subtitle file.

Not included: sample libraries (downloaded by the library's `tools/fetch.sh`), the Kokoro voice model, and rendered outputs.
