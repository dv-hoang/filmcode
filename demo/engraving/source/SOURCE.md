# The Night Lamp — build notes

38.0 s, 1920×1080, 24 fps. One command: `sh build.sh` from this folder (or any cwd; the script finds itself). It expects `LIB` or `~/.filmcode/library`.

Picture is `render(t)` in `scene.js`: laid paper, swelling hatches, a copper opening, a burnished window, one roundel, one amber wash. Voice is Kokoro `af_heart`. The score is harpsichord then viola at 66 BPM. Mastering is `core/render/mux.sh` to −14 LUFS, grain 1.

The library demo is a honeybee museum label. This film is a different plate: three states of one invented seed, ending on the seed at natural size.
