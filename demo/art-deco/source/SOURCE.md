# Night Elevator — source

A real Art Deco film: lacquer black, engraved gold, one vertical axis — the last
lift of the night racing midnight to the roof.

## Build

```bash
export LIB="$HOME/.filmcode/library"
sh build.sh
```

Outputs: `night-elevator.mp4`, `out/video.mp4`, `audio.wav` (intermediates gitignored).

## Files

- `index.html`, `film.js` — deco geometry, dial, doors, roof sign.
- `audio.py` — pad, floor chimes, power dip, finale.
- `fonts/` — Limelight, Poiret One, Josefin Sans (OFL).
