# One Ember source

Source for the Woodcut Print demo film under `demo/woodcut/`, 38 s.
Layout follows the Impasto demo (`demo/impasto/source/`).

## Build

Set `LIB` to the FilmCode library folder (the one with `core/` and `.venv/`):

```bash
export LIB="$HOME/.filmcode/library"
sh build.sh
```

`build.sh` synthesises voice (once), checks it, renders the film, generates the
score, mixes audio and writes:

- `one-ember.mp4` — final render (also copied to `demo/woodcut/one-ember.mp4`)
- `../poster.jpg` — poster frame
- `../one-ember.srt` — subtitles
- `out/video.mp4`, `out/mix.wav` — intermediates

Those outputs are gitignored. `music/music.wav` is regenerated by `music/score.py`.

## Inputs

Included: the browser film (`index.html`, `main.js`, `scene.js`, `engine/woodcut.js`),
the timeline (`timeline.json`), audio (`mix.py`, `music/score.py`), voice lines
(`tts/lines.json`), fonts, treatment.

Not included: the Kokoro voice model, a Whisper model for the speech check, and
rendered outputs.
