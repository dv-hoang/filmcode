# Data Flow Demo

This demo visualises a simple oscillating data set as a bar chart and line chart. The bars represent individual data points that change sinusoidally over time, while the line chart overlays the aggregated trend. The animation runs for 10 seconds, matching the audio track which plays a continuous 440 Hz sine wave.

The code is intentionally minimal, using only the Canvas 2D API and system fonts. No external resources are fetched at runtime.
