# Halftone Dossier — Source

- `source/index.html` – canvas container
- `source/film.js` – 10 s Canvas 2D rendering, halftone-dossier style
- `source/audio.py` – generates `audio.wav` (10 s ambient)
- `source/build.sh` – renders video via `$LIB/core/render/video.mjs`, muxes audio, writes `.mp4`
- `DEMO.md` – demo metadata

All code is original; no external fetches at runtime.
