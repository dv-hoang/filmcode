# Global Lithium Surge — Social Caption Explainer

A 10-second social-video news explainer built for sound-off viewing, following the "social-captions" style guidelines.

- **Scene 1 (0.0s - 2.8s):** Hook with huge slamming captions, yellow keyword highlights (`LITHIUM`), and a source badge.
- **Scene 2 (2.8s - 6.4s):** Document proof sliding in from the right, highlighted source table, and a rolling number metric (`+312%`).
- **Scene 3 (6.4s - 10.0s):** Takeaway headline banner and call-to-action for feed engagement.
