# LiDAR Survey

An airborne laser scanner passes through a ruined structural archway, projecting a cutting plane through thousands of real LiDAR return points colored by elevation.

- **Visual Style**: Real-time 2D canvas point cloud rendering with depth sorting, height-based chromatic mapping, and active slicing plane.
- **Audio Design**: Instrumentation hum, rhythmic laser return pings, and data capture pulses.
