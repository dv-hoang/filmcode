# First Orange source

Source for the Impasto Oil Painting demo film under `demo/impasto/`, ~42 s.
Layout follows the Watercolor demo (`demo/watercolor/source/`).

## Build

Set `LIB` to the FilmCode library folder (the one with `core/` and `.venv/`):

```bash
export LIB="$HOME/.filmcode/library"
sh build.sh
```

`build.sh` synthesises voice (once), renders the film, generates the score, mixes
audio and writes:

- `first-orange.mp4` — final render (also copied to `demo/impasto/first-orange.mp4`)
- `../poster.jpg` — poster frame
- `../first-orange.srt` — subtitles
- `out/video.mp4`, `out/mix.wav` — intermediates

Those outputs are gitignored where listed. `music/music.wav` is regenerated by `music/score.py`.

## Inputs

Included: the browser film (`index.html`, `main.js`, `scene.js`, `engine/impasto.js`),
audio (`mix.py`, `music/score.py`), voice lines (`tts/lines.json`), fonts, treatment.

Not included: sample libraries (downloaded by the library's `tools/fetch.sh`), the
Kokoro voice model, and rendered outputs.
