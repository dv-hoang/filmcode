# Still Lit source

Source for the Urban Sketch · Pen & Wash demo film under `demo/urban-sketch/`, 40 s.
Layout follows the Impasto demo (`demo/impasto/source/`).

## Build

Set `LIB` to the FilmCode library folder (the one with `core/` and `.venv/`):

```bash
export LIB="$HOME/.filmcode/library"
sh build.sh
```

`build.sh` synthesises voice (once), checks it, renders the film, generates the score,
mixes audio and writes:

- `still-lit.mp4` — final render (also copied to `demo/urban-sketch/still-lit.mp4`)
- `../poster.jpg` — poster frame at the lit window
- `../still-lit.srt` — subtitles
- `out/video.mp4`, `out/mix.wav` — intermediates

Those outputs are gitignored where listed. `music/music.wav` is regenerated by `music/score.py`.

## Inputs

Included: the browser film (`index.html`, `main.js`, `scene.js`, `engine.js`),
audio (`mix.py`, `music/score.py`), voice lines (`tts/lines.json`), the Caveat font,
treatment, credits.

Not included: sample libraries (downloaded by the library's `tools/fetch.sh`), the
Kokoro voice model, and rendered outputs.
