# Source Code

This demo is a 10‑second film that showcases a rotating glass cube with a light sweep effect. The film is written entirely in JavaScript using the 2‑D canvas API. The audio is a simple 440 Hz sine wave generated by a small Python script.

## Files

- **source/index.html** – The entry point that loads the canvas and the film script.
- **source/film.js** – The rendering logic. It defines `window.DUR`, `window.render`, and sets `window.READY`.
- **source/audio.py** – Generates a 10‑second mono WAV file.
- **source/build.sh** – Builds the final MP4 by rendering frames and muxing the audio.
- **source/SOURCE.md** – This file.
- **source/CREDITS** – Credits (none).
- **demo/glass-product/DEMO.md** – Demo description.

The film uses only system fonts and no external resources, keeping it lightweight and portable.
